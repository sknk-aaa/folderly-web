フォルダアイコンが変更できない・
反映されない時の対処法

アイコンを変えたはずなのに反映されない。せっかく設定したのに、再起動したら元の黄色いフォルダに逆戻り——。Windowsのフォルダアイコン変更は、実はつまずく人がとても多いところです。

この記事では、まずWindows標準の正しい変更手順を確認し、そのうえで「なぜ反映されないか」「なぜ元に戻るか」「どう直すか」を症状別に切り分けます。

まず結論

まず手順を確認。その後「キャッシュ」「参照切れ」「形式」「場所」を切り分ける。

フォルダアイコンが変わらない時は、いきなりキャッシュ削除に進むより、最初に「標準の手順で .ico を指定できているか」を確認するのが近道です。手順が合っているのに反映されないならキャッシュ、再起動後に戻るなら desktop.ini やアイコンファイルの参照切れを疑います。

手順確認まず、Windows標準の変更方法が合っているか確認

「変更できない」と感じる時でも、実は手順の途中で違う場所を開いている、または選べるファイル形式が違うだけのことがあります。まずは、通常のフォルダで次の流れになっているか確認してください。

  1. 変更したいフォルダを右クリックして、プロパティを開く。
  2. カスタマイズタブを開き、アイコンの変更を押す。
  3. 参照から .ico ファイルを選ぶ。JPG/PNGは標準機能では基本的に選べません。
  4. OK、適用、OK の順に押し、エクスプローラーで表示を確認する。
確認ポイント操作しているのは通常のフォルダですか？ ライブラリや特殊フォルダでは、同じ手順にならないことがあります。
ファイル形式Windows標準のアイコン変更では、基本的に .ico を指定します。写真の .jpg や .png はそのままでは選べません。
反映確認適用直後に見た目が変わらない場合でも、設定自体は保存されていることがあります。次の原因別セクションで表示更新を確認します。

仕組みWindowsは desktop.ini とアイコンファイルを見ている

フォルダアイコンの変更は、見た目よりも少し裏側の仕組みが重要です。Windowsはフォルダ内のカスタマイズ情報を desktop.ini に保存し、そこからアイコンファイルを参照して表示します。Microsoftのドキュメントでも、フォルダのカスタマイズは desktop.ini で定義でき、アイコンには .ico 形式が推奨されています。

つまり、設定した後にアイコンファイルを動かしたり、desktop.ini が同期や整理で消えたりすると、Windowsは「どのアイコンを表示すればいいか」を見失います。これが、再起動後に元へ戻る原因になりやすいです。

実スクショ差し替え予定：desktop.ini と .ico が見えるフォルダ 推奨ファイル名：/assets/fix-desktop-ini.webp
隠しファイルと拡張子を表示した状態で、個人情報のないテストフォルダを撮影。

原因早見表つまずく原因は、大きく4つ

手順が合っているのにうまくいかない場合は、症状ごとに原因を切り分けます。自分の状態に近いところから読んでください。

反映されない設定は保存されているが、Windowsのアイコンキャッシュやエクスプローラー表示が古いまま残っている。
元に戻る指定した .ico の場所が変わった、または desktop.ini が消えた・上書きされた。
写真が選べない標準機能は .ico 前提。JPG/PNGを使うには変換か専用アプリが必要。
変更ボタンがない特殊フォルダ、権限不足、読み取り専用、ネットワークフォルダなどで標準手順が使えない。

症状 1変更したのに反映されない

「OKを押したのに、見た目が変わらない」。これはアイコンキャッシュが原因のことがほとんどです。Windows は表示を速くするためにアイコンを一時保存していて、古い表示が残ってしまうことがあります。設定自体は成功しているので、表示を更新してあげれば直ります。

  1. まず、対象フォルダのひとつ上の階層を開き直すか、エクスプローラー上で F5（更新）。
  2. 直らなければ、タスクマネージャー（タスクバー右クリック → タスクマネージャー）で「エクスプローラー」を選び、〔再起動〕。
  3. それでもダメなら、いったん PCを再起動。多くはこれで反映されます。
実スクショ差し替え予定：タスクマネージャーでエクスプローラーを再起動 推奨ファイル名：/assets/fix-restart-explorer.webp
「Windows エクスプローラー」と「再起動」ボタンが見える状態。
上級者向け：アイコンキャッシュを手動でクリア
タスクマネージャーでエクスプローラーを終了 → コマンドプロンプトで del /a %localappdata%\IconCache.db と del /a %localappdata%\Microsoft\Windows\Explorer\iconcache* を実行 → エクスプローラーを再起動。コマンド操作に慣れている場合のみどうぞ。
毎回キャッシュ更新でつまずく場合
Folderlyは適用後に表示更新まで行うので、変更したのに反映されないストレスを減らせます。

症状 2設定しても、しばらくすると元に戻る

「変えたのに、再起動したら元通り」「数日後に黄色いフォルダに戻っていた」。これは標準のアイコン変更が、指定したファイルの“場所を覚えているだけ”という仕組みだからです。次のどれかが起きると、参照が切れて元に戻ります。

  • アイコンに指定した .ico ファイルを移動・削除・リネームした
  • 設定を保存している隠しファイル desktop.ini が消えた・書き換わった
  • OneDrive などのクラウド同期が desktop.ini を上書きした

対処は「参照が切れないようにする」こと。.ico は移動しない安全な場所（理想はそのフォルダの中）に置き、desktop.ini は消さない。同期フォルダ内では起きやすいので、同期対象から外すか、別の方法を検討します。

実スクショ差し替え予定：アイコン用 .ico をフォルダ内に置く例 推奨ファイル名：/assets/fix-icon-file-location.webp
テストフォルダ内に folder.ico と desktop.ini がある状態。個人情報のないフォルダ名で撮影。

そもそも「ファイルの場所を覚えているだけ」が原因。
画像を内部で抱えてくれる方法なら、移動しても削除しても戻りません。

画像を移動しても戻りにくくしたい場合
Folderlyは選んだ画像をアプリ側で管理します。元画像を整理しても、設定したフォルダアイコンを保ちやすくなります。

症状 3写真（JPG / PNG）が選べない

「アイコンの変更」を開いても、手持ちの写真が一覧に出てこない——これは仕様です。標準機能が受け付けるのは .ico という専用形式（と一部の .exe / .dll）だけ。スマホやカメラの JPG・PNG は、そのままでは指定できません。

解決策は2つです。

  • 画像を .ico に変換するツールを探して使う（ひと手間かかります）
  • 変換が不要なアプリを使い、写真をそのままドラッグして指定する
写真やPNG/JPGをそのまま使いたい場合
Folderlyなら.ico変換なし。写真と色タグで、仕事・写真・資料フォルダを見分けやすくできます。

症状 4「アイコンの変更」が見つからない・押せない

プロパティを開いても「カスタマイズ」タブや「アイコンの変更」が見当たらない場合、そのフォルダが対象外のことがあります。

  • 特殊フォルダ（ドキュメント・ピクチャ等）やライブラリを操作している → 設定箇所が異なります
  • ネットワークドライブ・読み取り専用・権限不足 → 書き込みできず変更が反映されない、またはWindows側が表示を無視することがあります

通常のフォルダを右クリック →「プロパティ」→「カスタマイズ」タブの順で開けば、「アイコンの変更」が出てきます。カスタマイズタブ自体が無いフォルダは、標準機能では変更できません。

ネットワークフォルダについて
NAS・共有フォルダ・ネットワークドライブは、Windowsやファイルサーバーの設定によって desktop.ini による見た目の変更が表示されない場合があります。Folderlyはローカルフォルダでの利用を推奨しています。

補足Windows更新やネットワークフォルダが関係する場合

最近になって急にフォルダアイコンが表示されなくなった場合は、Windows更新の影響も確認します。Microsoftは、2026年6月以降のWindowsセキュリティ更新後、一部の desktop.ini によるカスタムフォルダアイコンやローカライズ名が表示されない場合があると案内しています。

特に、ダウンロード元が信頼されていないファイル、ネットワーク上の場所、NASや共有フォルダなどでは、Windowsやファイルサーバー側のセキュリティ設定で desktop.ini の表示カスタマイズが無視されることがあります。この場合、アプリや手順の問題ではなく、Windows/サーバー側の扱いが原因の可能性があります。

切り分けのコツ
同じアイコンを、まずローカルの通常フォルダ（例：デスクトップ上のテストフォルダ）で試してください。ローカルでは反映され、NASや共有フォルダだけ反映されない場合は、ネットワーク側の制限である可能性が高いです。

参考：Microsoft Support: Custom folder icons might not appear after installing the June 2026 Windows security update

根本解決二度とつまずかないために

ここまでの原因——形式の制限・ファイル移動で戻る・キャッシュで反映されない——は、その多くが標準機能の仕組みに由来します。私たちが作った Folderly は、ここを構造から解決しています。

  • .ico 変換は不要。写真（PNG / JPG）をドラッグするだけ（症状3の解決）
  • 画像を内部にコピーして管理するので、元画像を移動・削除しても戻らない（症状2の解決）
  • 適用後に表示を自動更新するので、キャッシュで悩まない（症状1の解決）
  • 気が変わっても履歴からワンクリックで元に戻せる
